# Планирование: анализ, идентификация проблем и поиск решений

## 1. Проблемные места

1. для каждой системы используется только 1 инстанс
2. БД используется и на чтение и на запись
   1. возможно нужно решение которое позволяет быстро читать данные - в том числе с кэшем
3. Есть два потока принятия заказов которые нужно разграничить чтобы они не влияли.
   1. Например заказы принятые по API можно обрабатывать через брокер сообщений чтоб не тормозить общий процесс
4. Возможно надо как-то разграничивать сложные и несложные модели чтобы анализировать их по отдельности и сложные модели не тормозили оценку простых. Но для начала нужно получить статистику кол-ва сложных и несложных моделей и какие из низ приносят наибольшую прибыль. Также нужно проверить возможность быстро определять сложность модели чтобы отделять модели по сложности на этапе передачи в процессинг.
5. На подумать: может поменять брокер с RabbitMQ на Kafka
6. Медленная прогрузка списка заказов в MES
7. В CRM только один сервис который обрабатывает и заказы и разных систем (онлайн магазин и MES) и управление производством (когда продавец подтверждает заказ)
